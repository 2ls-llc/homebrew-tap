# Two Ls LLC Homebrew tap

```sh
brew install 2ls-llc/tap/timi
```

| Cask | App |
| ---- | --- |
| `timi` | [Timi](https://github.com/2ls-llc/timi): a pixel cat that lives on your desktop and keeps your focus timer |

Timi isn't notarized by Apple yet, so macOS blocks her first launch. Open Timi
once and click **Done**, then go to **System Settings → Privacy & Security** and
click **Open Anyway**. Each update needs this once more until releases are signed.
